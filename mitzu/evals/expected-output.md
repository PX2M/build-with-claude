# Expected output: the battle card

Written BEFORE the run. This is the acceptance spec, not a transcript of a good run.

## It passes if
- [ ] Three to five objections, each one a sentence a real rep has heard.
- [ ] Every objection has: why it lands, what to say back, one source (a URL on the competitor's site).
- [ ] At least one "where we lose" case, stated plainly, with the walk-away line.
- [ ] Nothing a competitor could also say. Every response is only true of Mitzu.
- [ ] Skimmable in ninety seconds. Headings, short lines, no paragraphs.
- [ ] No number that is not on a source page.

## It fails if
- It flatters us. No losing case, or the losing case is a compliment in disguise.
- It attacks a feature instead of asking what the feature runs on.
- A signal made the card without touching cost, sampling or data movement.

## Scorecard (1 to 5 each, after the run)
| Dimension | Score | Why |
| --- | --- | --- |
| Ownability: could only we say this? | | |
| Provability: does every line carry a source? | | |
| Recognition: would the buyer recognise the objection? | | |
| Buyer urgency: does the response give them a reason to move now? | | |

Anything under 3 is a brief fix, not a prompt fix. Edit compete-agent.md and run again.
